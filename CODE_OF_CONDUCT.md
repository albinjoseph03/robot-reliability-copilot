# Community code of conduct

Everyone participating in this project should be able to contribute without
harassment. Be respectful, welcome differing experience levels, critique ideas
and code constructively, and acknowledge mistakes without personal attacks.

Harassment, threats, discriminatory language, sexual attention, doxxing,
impersonation, and deliberate disruption are unacceptable. These standards
apply to project issues, pull requests, discussions and project events.

Report concerns privately to a repository maintainer through a private contact
listed on their hosting profile. Do not post private incident details publicly.
If no private contact is available, use the host's abuse-reporting tools.
Maintainers should protect reporter privacy, disclose conflicts of interest,
and arrange another maintainer's review when needed.

Responses may include a private correction, warning, temporary suspension or
permanent exclusion, proportionate to the behavior and repeated violations.
An affected participant may request review by a different maintainer where
available. Good-faith reports and requests for review must not invite
retaliation. This is a project-specific policy, not a claim of affiliation with
an external conduct enforcement body.
